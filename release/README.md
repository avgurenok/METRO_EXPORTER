# MetroEX — готовая сборка под Windows

Распаковщик и конвертер ресурсов Metro 2033 Redux и Metro: Last Light Redux.
Собирать ничего не нужно — всё, что требуется программе, лежит в этой папке.

## Как запустить

1. Скопировать **всю папку целиком** в любое место на диске.
2. Запустить `MetroEX.exe`.

Файлы рядом с `.exe` — это его библиотеки. Если вынуть `MetroEX.exe` из папки
отдельно, он не запустится.

**Что нужно от системы:** Windows 10 или 11, 64-битная. Больше ничего ставить не
надо — .NET Framework 4.8 входит в состав Windows 10 начиная с версии 1903 и в
Windows 11, а видеодрайвер с Direct3D 11 есть на любой машине этих лет.

## Как пользоваться

**Открыть архив игры.** Кнопка с папкой в левом верхнем углу, затем файл
`content.vfx` в каталоге установленной игры. Остальные файлы архива (`content.vfs0`,
`content.vfs1` и так далее) программа подхватит сама — выбирать нужно именно `.vfx`.
Архив большой, первое открытие занимает секунд десять.

**Найти модель.** Строка поиска над деревом фильтрует по имени. Модели лежат в
`content\meshes\`, текстуры — в `content\textures\`.

**Посмотреть.** Одиночный клик по `.model` показывает модель в правой панели.
Список её анимаций — внизу, кнопка `Stop` останавливает проигрывание.

**Выгрузить.** Правый клик по `.model` → **Save as FBX...**

Рядом с `.fbx` появятся файлы текстур в формате `.png`. Они же вшиты внутрь самого
`.fbx`, так что если переносить модель на другую машину, достаточно одного файла.

Правый клик по папке в дереве даёт **Extract folder with conversion...** — выгружает
всё её содержимое разом.

## Импорт в Blender

`File → Import → FBX (.fbx)`, настройки по умолчанию.

Модель придёт в метрах, с текстурами, со скелетом и со всеми анимациями — каждая
отдельным action, переключаются в Dope Sheet → Action Editor.

## Что стоит знать заранее

**Анимаций может быть много.** У человеческих персонажей их несколько тысяч на один
скелет, и грузить все — это минуты ожидания и гигабайты памяти. Программа берёт
первые 256 и пишет в лог, сколько пропустила.

**Персонаж шагает на месте.** Blender при импорте поглощает корневую кость в объект
арматуры, поэтому перемещение персонажа по сцене теряется — сама анимация тела при
этом проигрывается правильно. Это поведение импортёра Blender, а не экспорта.

**Metro Exodus не поддерживается** в той же мере, что Redux. Формат архивов там
третьей версии, часть кода для него есть, но проверялось всё на Redux.

## Что в этой папке

| Файл | Зачем |
|---|---|
| `MetroEX.exe` | сама программа |
| `libfbxsdk.dll` | Autodesk FBX SDK, им пишется `.fbx` |
| `ObjectListView.dll` | список файлов в интерфейсе |
| `msvcp140.dll`, `vcruntime140.dll`, `vcruntime140_1.dll` | runtime Visual C++ |

Программа пишет `log.txt` рядом с собой — если что-то не открылось или не
выгрузилось, причина будет там.
